# weixinpaiban

本项目提供一套可复用的微信公众号文章模板能力：

1. 本地公众号排版与导出页面（静态部署）。

## 已实现

- 本地排版预览、复制、下载 HTML
- 模板正文末尾固定附带底栏结语与关注引导

## 部署为静态页面

- 直接将仓库根目录下的 `module.html` 与 `src` 目录一起部署到静态托管服务（GitHub Pages、Netlify、Vercel 等）。

- 本地预览：直接在浏览器中打开 `module.html`。

## 使用说明

- 直接打开 `module.html` 即可在浏览器中进行文章排版、复制与下载。

模板渲染器导出接口位于 `src/wechat-template.js`，可在需要时由后端或其他工具调用。

## 模板说明

- 正文采用 Markdown 格式，支持 `##`（小标题）、`>`（引用）、`---`（分隔符）、无序/有序列表、`**加粗**`、`*斜体*`、`[链接](https://example.com)` 等常见语法。
- 换行即视为块级切换：每个换行会被视为新的块（单换行可分隔段落或触发块语法）。
  - 模板结尾会自动附带底栏结语作为结语与关注引导。

## 本地页面

- 直接打开 [module.html](module.html) 即可使用排版预览、复制和下载功能
-- 页面为独立静态预览与导出工具，输出由 `src/wechat-template.js` 提供

## 当前限制

- 账号名片目前是固定占位区，不包含独立可配置字段
- 页面默认隐藏标题、作者、日期输入，因此模板输出聚焦正文和文末结语区
